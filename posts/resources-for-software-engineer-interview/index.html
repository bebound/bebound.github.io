Resources for Software Engineer Interview

Here are some resources I use to prepare for software engineer interview. I hope these resources will help you too.

LeetCode

LeetCode still plays a important role in the interview process, both in online assessment and onsite interview. I personally think the LeetCode can only test whether one has a good memory or fortune. It can’t judge whether one is a good engineer or not. Before LeetCode is replaced by AI coding interview, we still need to practice it. Here are some resources I found useful.

  1. LeetCode 101: This website contains the most common LeetCode problem types, including binary search, DFS, BFS, dynamic programming, etc. It’s a good starting point to practice LeetCode.
  2. Coding Interviews: Questions, Analysis & Solutions (Expert’s Voice in Programming) (剑指Offer：名企面试官精讲典型编程题) and Cracking the Coding Interview: 189 Programming Questions and Solutions (程序员面试金典) are two classic books.
  3. After you have read the above resources, you can used LeetCode Top 100 Liked Questions and LeetCode Top Interview 150 to practice.

System Design

If you are applying for senior position, you need to prepare for system design problem. System Design in a Hurry is a good starting point. It shows the common delivery framework to solve the problem and lots of classic problems to help you understand the framework.

System Design Interview – An Insider’s Guide and System Design Interview – An Insider’s Guide: Volume 2 contains more examples. Jordan has no life created a series of videos about the system design as well. Designing Data-Intensive Applications is a classic book about system design. It covers the fundamental topics of system design, you should read it if you want to knows more besides passing the interview.

Project Deep Dive

The interviewer should also ask you about the projects you have listed on the resume. You need to prepare for this part as well. You should be able to stat the problem you are trying to resolve, the solutions and the outcome, or even the plan for the next step. You should also be able to answer why you choose that solution, what’s the trade-off, is there any better solution, etc.

Behavioral Questions

The manager or director round focuses on the behavioral questions. There is no good resource for this part, the questions vary from company to company. Don’t be nervous, just be yourself and be honest and positive. Some common questions are: why join this company, what’s the most proud project you have, what if you disagree with others, how to arrange your work.

SQL

Some positions also require SQL knowledge. I believe LeetCode Top SQL 50 is enough to prepare for SQL interview.

Miscellaneous

You can also get some information such as the interview process, interview experience, package from 1point3acres, Blind or Reddit.

Good luck for your interview!
